# BiteDetector
Purpose: This project is built to solve a problem that many anglers have: figuring out whether a fish is biting their lure or if the envrionment is playing with them. With an inbuilt vibration sensor and a custom threshold, this project customizes the detection system based on the weather.

How it works:
This project uses a piezoelectric sensor that is mounted to the rod which then is fed vibrations when the rod is experiencing motion. There is a potentiometer that can be turned up or down to filter out noise, hence changing the sensitivity. There are 2 switches to turn on the detector and power the sensors. There is a passive buzzer along with an LED to indicate if you are experiencing a bite. The motion is displayed on a 16x2 lcd, along with your threshold.
